# Vitako

Plus fort. Plus sain. Plus malin.

Site de la marque Vitako : programmes de musculation, menus personnalisés et comparateur de prix de courses.

- `index.html` : le site (un seul fichier, version maquette : données de démonstration, textes légaux à compléter).
- `vitako-stripe/` : serveur Stripe (Checkout + Billing, mode test). Voir son README.

Ne publie jamais de clé secrète Stripe : elle va dans `vitako-stripe/.env`, ignoré par Git.
